## Проекты:

### ~ 1 ~ ___Дипломный проект курса___

__Задача__:

Разработать _backend_ для сервиса заказа товаров, автоматизирующий закупки в розничной сети

__Выполнение__:

В ходе работы последовательно делал коммиты. Прорабатывал процесс аутентификации по _JWT_. Задал регистрацию
пользователей с подтверждением профиля через код приходящий на почту. Настроил отмену транзакций к БД в случае 
возникновения ошибок со стороны клиента или сервиса не позволяющей передать не полные данные. Написал _vewv`s_/представления
и разрабатывал _API_ по взаимодействию с сервисом. Организовал передачу задача по отправке _email_ и обработке большого прайса партнера в приложение 
_Celery_. Докеризировал проект. 

__Результат__:

Готовый _REST API_ для работы с сервисом, позволяющий пользователям зарегистрироваться, смотреть интересующие товары, пользуясь различными фильтрами,
формировать корзину покупок и делать заказы. Партнёры сервиса используя оформленный по документации _yaml_-файл могут обновлять свои товары на сервисе.

Репозиторий проекта >>> [Procurement_service_on_Django](https://github.com/XBA-bit-total-control/Procurement_service_on_Django.git)


### ~ 2 ~ ___Upscaling_with_celery___

__Задача__:

Написать _API_ к готовой модели машинного обучения применяя _Celery_

__Выполнение__:

Используя фреймворк _Flask_ создал 3 эндпоинта для отправки запроса на апскейлинг фото, получения статуса и результата выполнения задачи.
Делегировал долгую задачу апскейлинга приложению _Celery_. Реализовал 5 поддерживаемых типов входящего фото для обработки. Написал тесты на _pytest_ для проверки 
корректности работы. Докеризировал приложение и написал документацию.

__Результат__:

Приложение на _Flask_ для апскейлинга поддерживающее в запросе фото типа _png_, _jpg_, _jpeg_, _tiff_ или _bmp_ и отправляющего задачу в _Celery_, можно проверить статус задачи
и получить готовый результат в виде обработанного фото переданного формата. 

Репозиторий проекта >>> [Upscaling_with_celery](https://github.com/XBA-bit-total-control/Upscaling_with_celery.git)


### ~ 3 ~ __FastAPI_classifieds_website_part_2__

__Задача__:

Реализовать на _FastAPI_ и сервис объявлений купли/продажи с разделением прав доступа, аутентификацией и 15 эндпоинтами.

прав на доступ/изменение ресурса. Асинхронным вариантом создал _view`s_. Оформил типизацию, _dockstring_ и документацию. Докеризировал приложение.

__Результат__:

Быстрое благодаря _FastAPI_ и асинронному подходу _API_-приложение для сервиса объявлений. Реализованная аутентификация по _JWT_ и авторизация.
Возможность запуска в контейнере. 

Репозиторий проекта >>> [FastAPI_classifieds_website_part_2](https://github.com/XBA-bit-total-control/FastAPI_classifieds_website_part_2.git)
